# Bank Management System

A console-based banking application developed using C++.

## Features
- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Display all accounts
- Store account records using file handling

## Concepts Used
- Object-Oriented Programming (OOP)
- Classes and objects
- File handling
- Functions and conditional statements

## How to Run

Compile the program:

```bash
g++ BankManagement.cpp -o BankManagement.exe
```

Run the application:

```bash
.\BankManagement.exe
```

## Language
C++
